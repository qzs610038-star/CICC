# PPT 与技术文档大纲：本机参考资料约定

## 入口

- [本机资料库完整索引](REFERENCE_LIBRARY_INDEX.md)：按“用途—文件—相对链接”检索 39 个非图片主资料。
- [项目内 PPT/技术文档 skill](../.agents/skills/cicc-ppt-tech-docs/SKILL.md)：统一资料路由、事实边界和交付前校验。

## 使用边界

1. 先用 [本机资料库完整索引](REFERENCE_LIBRARY_INDEX.md) 找结构、图表和表达方式；不要把参考案例中的实现、指标或测试结果写成当前项目事实。
2. 涉及赛题、评分、当前状态、接口、源码、构建或板级结论时，分别回查官方细则、CURRENT_STATE.md、真实工程文件与匹配证据。
3. 在本目录新增引用时，只使用 ../CICC技术文档与PPT收集整理/... 相对路径；不写机器相关的 file:/// 绝对路径。
4. Agent 可调用项目内 [cicc-ppt-tech-docs skill](../.agents/skills/cicc-ppt-tech-docs/SKILL.md)，按统一的证据边界、写作流程和链接校验完成任务。

`ppt_doc_outlines/` 中纳入 Git 的大纲、草稿和后续文档任务，可按相对路径访问仓库根目录下的 [CICC技术文档与PPT收集整理](../CICC技术文档与PPT收集整理/) 作为参考资料库。

该资料库已被 `.gitignore` 忽略：不纳入 Git、不随提交或拉取同步，由资料持有人手动分发给队友。使用这些参考资料时，项目事实、官方细则、`CURRENT_STATE.md` 与真实源码仍是权威来源；参考库不构成已验证的项目证据。

建议按需优先查阅：

- `04_赛事官方要求与模板/`：技术文档与 5 分钟答辩的结构、格式和盲审要求。
- `01_第九届官方优秀作品专刊/`：可借鉴的技术表达与图表组织方式。
- `03_各方向优秀作品技术文档/`：FPGA 视觉、RISC-V/SoC、机械臂等专题写作参考。
