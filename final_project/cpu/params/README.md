# CPU 参数格式

本目录保存阶段 2 以后会频繁调整的参数。第一版采用 C 源码/头文件，便于直接纳入板上 CPU 构建；后续可增加串口或寄存器热更新，但文件名和语义保持稳定。

## 文件约定

- `color_thresholds.c`：颜色阈值表，使用 C 结构体数组，字段至少包含颜色 ID、RGB/Bayer 比值阈值、亮度上下限和饱和度/背景过滤条件。
- `shape_params.h`：形状分类参数，包含 bbox 宽高比、面积上下限、填充率、边缘/轮廓辅助阈值。
- `size_calibration.c`：像素/cm 标定表，按相机高度、ROI、物块尺寸档位记录阈值。
- `arm_positions.h`：机械臂点位表，包含安全位、抓取位、放置位、速度和夹爪参数。
- `task_config.h`：现场任务模式、目标颜色/尺寸、`cube_only_guard` 和调试开关。

所有参数修改都应在 `docs/bringup/` 或测试记录中写明样本、光照、相机高度和验证结果。
