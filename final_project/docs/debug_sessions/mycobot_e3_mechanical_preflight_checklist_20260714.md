## 1. E3 通过条件（全部勾选才 PASS）

- [ ] **E3-1 基座刚性固定**：机械臂底座与工作台之间无可见相对位移；连接处采用多点/三角支撑，不依靠胶带、软垫或夹压外壳。
- [ ] **E3-2 安装版本标记**：底座、乐高连接件、工作台三处刻有或贴有对齐标线；标线位置拍照存档，编号写入本单。
- [ ] **E3-3 外部 180°基准**：在工作台上设置独立于机械臂的外部角度基准（量角器/直尺/激光），能直接读出“投放点相对起点旋转 180°±10°”。
- [ ] **E3-4 净空**：机械臂最大臂展（约 280 mm）范围内无人员、无易碰物品；投放区半径 ≥ 150 mm 内清空。
- [ ] **E3-5 急停/断电人**：现场有一名安全员手持机械臂独立 12V 电源开关；能在异常 1–2 秒内断电；断电后舵机自由，不自动释放扭矩。
- [ ] **E3-6 物块与台面**：五色物块（白/黑/红/蓝/黄）、三形状（正方体/非正方体）、三尺寸（2cm/2.5cm/3cm）齐全并拍照；台面颜色与物块对比度足够；台面固定不动。
- [ ] **E3-7 双人复核签字**：至少两人（操作员 + 安全员）现场复核上述六项，并在本单 §4 签字。

## 2. 现场测量方法（最小可重复）

### 2.1 基座位移复核（E3-1 核心）

1. 在底座、乐高连接件、工作台三处贴对齐标线（细记号笔或薄胶带，宽度 ≤ 1 mm）。
2. 机械臂独立上电，手动施加轻微横向载荷（≤ 5 N，约 500 g 重物轻压末端），保持 3 秒后释放。
3. 用直尺或卡尺测量标线相对位移；记录三次测量的最大值。
4. **判据**：最大相对位移 ≤ 0.5 mm → PASS；> 0.5 mm 或可见滑移 → FAIL，需重新加固。

### 2.2 外部 180°基准测量（E3-3 核心）

1. 在工作台上标记“起点”（机械臂 HOME 正前方，最大臂展处）和“投放点”（相对起点旋转 180°）。
2. 用量角器或激光水平仪测量起点→投放点的旋转角；记录三次读数。
3. 同时用直尺测量投放点到底座中心的直线距离（应接近最大臂展 ~280 mm，但不超过 R_MAX_MM = 280 mm）。
4. **判据**：旋转角在 170°–190° 且距离 ≤ 280 mm → PASS；否则调整投放点标记后重测。

### 2.3 急停演练（E3-5 核心）

1. 机械臂处于任意非 HOME 姿态，独立 12V 上电。
2. 安全员口头喊“停”并立即断开 12V 电源。
3. 记录从喊“停”到电源断开的秒数（用手机计时）。
4. 确认断电后舵机自由、机械臂不自动回零、不自动释放扭矩。
5. **判据**：断电时间 ≤ 2 秒且断电行为符合预期 → PASS；否则重新明确断电方式和人手分工。

## 5. E3 PASS 后的下一步

1. 用户在本单 §4 签字并填写 §3 证据路径后，E3 视为 PASS。
2. 此时才能申请 E4 `--teach-only`，用全新唯一命名 JSON 保存五点；不得覆盖任何旧 JSON。
3. E4 完成后离线附加外部证据（E5 `--annotate-preset` + `--check-preset`），PASS 后才能申请 E6 无夹爪探针。
4. 任一阶段出现读回不稳、最大误差 > 2°、底座/安装标记位移、外部角度超界或碰撞风险，立即停止并使当前预设失效。

## 6. 与板上路线的边界

- E3 PASS 只解锁 PC 端 E4–E6 真机示教/探针；**不**解锁板上 G4–G11。
- 板上路线仍需用户先确认 Efinity 2025.2/许可证/JTAG/UART0 条件，生成同批次 SoC/bitstream/ELF，形成 G4 Review Packet。
- 单摄候选工程 `competition_project_single_camera/` 未完成 M0 板级复现前，PC 端 180°实验不能依赖该工程提供真实识别触发。
