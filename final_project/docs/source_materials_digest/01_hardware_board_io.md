## 队友需要带走的结论

- 开发板主目标是 WZZY_FPGA / TJ375N529，决赛主线围绕 MIPI 摄像头输入、FPGA 视频前端、板上 CPU 决策和 myCobot 控制。
- MIPI CSI-2 不是普通 GPIO。lane 数、RAW 位深、D-PHY 电平、相机初始化和 IP 配置必须与开发板接口、官方 demo 和实际摄像头共同确认。
- UART/JTAG 是调试和控制关键入口。机械臂 UART、调试 UART、JTAG/OpenOCD 不能混用概念；端口、电平、波特率和连接对象必须单独记录。
- 管脚、供电、电平和外设连接必须以官方管脚文档和最终 `final_project/integration/io_pin_map.md` 为准。任何上板接线前都需要再次核对。

## 风险边界

- 不从摘要中直接抄引脚号上板；摘要只告诉队友该查哪里、为什么要查。
- 不把 FPGA 输出线直接接入机械臂控制线，除非已经确认电平、串口方向、共地和协议。
- 不把摄像头 RAW 数据当作普通 RGB 图像处理。视觉分析需要考虑 Bayer 相位、黑电平、白平衡、gamma、曝光和现场光照。
