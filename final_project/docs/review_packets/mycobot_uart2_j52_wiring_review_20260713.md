## 1. 已确认的开发板侧事实

官方《开发板使用说明1V0(5).pdf》第 15 页（PDF 第 17 页）确认：

- 第三路 UART 位于右侧 `2.54 mm` 间距 `4Pin` 的 `J52` 座子。
- `FPGA_UART2_RXD = GPIOR_97 = C14 = Bank TR1`。
- `FPGA_UART2_TXD = GPIOR_101_PLLIN1 = F12 = Bank TR2`。

官方 `TJ375N529_PINOUT_CONFIGURATION.pdf` 第 3 页进一步确认：

- `C14 / GPIOR_97 / FPGA_UART2_RXD` 属于 `3.3V` I/O 域。
- `F12 / GPIOR_101_PLLIN1 / FPGA_UART2_TXD` 属于 `3.3V` I/O 域。

## 2. 必须保留的矛盾与未验证项

仓库内官方《机械臂mycobot280的安装及调试说明.pdf》第 5 页对 PC 端 USB-TTL 的原文连接写法为：

```text
TXD -> 机械臂 TX
RXD -> 机械臂 RX
GND -> 机械臂 GND
```

该命名与常规“发送端接接收端”的交叉接法存在表述冲突；资料也没有在同页给出机械臂底座信号脚的输入电压容限。因此：

- 本文件保存用户确认的正式候选：`C14/RXD <- 机械臂 TX`、`F12/TXD -> 机械臂 RX`、`GND <-> GND`、`VCC NC`。
- 不能仅依据 FPGA 端为 3.3V，就推断机械臂端已完成 3.3V 容限验证。
- “无需 USB-TTL、电气上可直接连接”当前为**条件结论**，不得替代实物测量和双人复核。
- USB-TTL/逻辑分析仪可以用于 D2 的断臂监听或回环验证，但不得未经批准串入正式板到臂控制链，也不得连接 J52 VCC 给机械臂供电。

## 3. 正式连接前的最小验证

所有检查在机械臂动作禁用、J52 第 4 针悬空的条件下完成：

1. 断电核对 J52 丝印、针脚 1 方向、GND 连通性和 4Pin 顺序，并由 A/C 双人签字。
2. 机械臂独立上电、开发板暂不连接信号线；测量机械臂 TX 空闲电平与 GND 参考，确认不会超过 C14 容限。
3. 开发板独立上电、机械臂断开；在 F12 上测量空闲电平和 `1,000,000 bps / 8N1` 波形。
4. 先通过 3.3V 兼容监听器或逻辑分析仪核对 `FE FE 02 20 FA`，完成 100/100 帧无臂验证。
5. 仅当双端电平、方向、共地和线序均签核后，才断电连接三根信号线；第一次连接仍只允许 `GET_ANGLES`，不得发送动作或夹爪命令。

任一读数异常、方向不确定、空闲电平超限或机械臂返回帧异常，立即断开信号线并保持 F1 / `ARM_DISABLED`。

## 4. 工程约束边界

未来正式工程的逻辑方向应为：

```text
FPGA_UART2_RXD  C14  Input
FPGA_UART2_TXD  F12  Output
```

但截至本次核查，正式 `final_project/fpga/efinity/constrain.sdc`、`mem_test.xml` 与 `top.v` 未检出 C14/F12/UART2 绑定。本次只保存真源，不修改生成文件或约束。后续约束、Interface Designer/periphery 和 `soc.h` 必须在单独 Review Packet 中联合审查，不能用本文件替代正式工程证据。
