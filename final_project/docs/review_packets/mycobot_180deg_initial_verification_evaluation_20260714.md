## 4. 明日上板放行边界

### 4.1 GO：可推进

1. 以该点位文件作为板上点表的候选数据基线，不把它描述为官方验收点表。
2. 推进 G4 正式 SoC/构建/PNR/STA 和 G5 机械臂断开的板上模拟。
3. 推进 D2/UART2 本地回环或监听，机械臂控制线保持断开；先达到既定 100/100 帧结果。
4. 板上状态机实现有界超时、失败即安全、单事务防重复触发，以及 `get_angles` 读回后的 3°软到位判定。
5. 夹爪正式路径实现 `0x69` 运动状态轮询与 `0x65` 位置窗口确认；位置确认仍不能替代夹持力/未滑落观察。

### 4.2 NO-GO：不能由本次结果直接放行

- 不直接连接 FPGA/UART2 到机械臂并发送动作帧。
- 不跳过 D2 无臂回环、D3 只读、线序/电平/共地核验与 Codex 动作 Review Packet。
- 不把内部坐标 177.72° 当作外部 180°与最大臂展的正式验收。
- 不删除大臂 45°回零硬门、280 mm 臂展硬限、超时故障态和物理断电急停边界。
