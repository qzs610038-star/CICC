# Debug Records

本目录用于记录上板测试、构建、仿真和联调过程中出现的问题、定位过程与修复结果。

## 记录规范

后续每次遇到报错或异常，按以下信息追加记录：

- 日期时间：
- 测试场景：
- 现象 / 报错：
- 影响范围：
- 相关文件 / 模块 / 信号：
- 初步判断：
- 定位证据：
- 修复内容：
- 验证命令 / 上板结果：
- 剩余风险 / 后续动作：

## 文件组织建议

- `board_debug_log.md`：上板测试、视频链路、机械臂联调等现场问题。
- `build_debug_log.md`：Efinity 综合、布局布线、bitstream 生成问题。
- `simulation_debug_log.md`：ModelSim / Questa 仿真问题。
- `notes/`：临时截图、日志节选、波形说明或外部工具观察记录。

正式排查记录应优先写入对应日志文件，避免只保存在聊天记录或临时窗口中。
