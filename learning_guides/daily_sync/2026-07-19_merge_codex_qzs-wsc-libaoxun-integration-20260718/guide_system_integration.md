## 1. 今日最核心的改动与经验

### 📌 核心点一: Goal 2 的 BLOCKED 没被抹掉，而是被新证据关闭

* **改动背景与问题**：`35b074c` 审查时确实缺 UART1 原子批次和 Hello ELF，因此当时 `BLOCKED` 正确。后来 libaoxun `72cc281` 与 WSC `13419d9` 补齐了固定输入。
* **源码剖析**：[Goal 2 复审](file:///D:/第十届集创赛-雄芯院材料/docs/agent_context/QZS_GOAL2_WSC_CPU_UART1_AUDIT_20260718.md#L104-L130) 保留旧时间线，同时给出当前唯一组合输入和 `APPROVE` 边界。
* **经验总结**：这像医院病历。旧的“禁食”医嘱不能偷偷删掉；新检查通过后，应追加“解除禁食”的时间、依据和责任人，未来才能解释为什么状态发生变化。

### 📌 核心点二: 三个人的分支不是三份整文件投票

* **改动背景与问题**：WSC 负责 CPU/Host，libaoxun 负责 Hard SoC/UART1 原子批次，QZS 负责最终状态、安全门和证据索引。合并按领域和固定 SHA 裁决，而不是谁的分支覆盖整个 `CURRENT_STATE.md`。
* **源码剖析**：当前来源、制品身份与剩余 blocker 见 [CURRENT_STATE.md](file:///D:/第十届集创赛-雄芯院材料/CURRENT_STATE.md#L13-L22) 和 [CURRENT_STATE.md](file:///D:/第十届集创赛-雄芯院材料/CURRENT_STATE.md#L67-L81)。
* **经验总结**：系统集成像三科会诊：影像科、外科和麻醉科各自签字，但最终手术单只能有一份，而且每个结论都要注明来自哪一科、哪次检查。

## 2. 可迁移的系统级工程经验

* **避坑警示**：集合分支 PUSH 成功不等于 `main` 已更新；Host PASS 不等于板级 PASS；I0 UART1 的批准永远不授权 UART2/J52 或机械臂动作。
* **通用方法论**：推进 Gate 前依次固定 ref/SHA、探测 merge tree、实际合并、fresh 测试、状态刷新、远端 SHA 复核。任何一步失败都保留单点故障，不用其他层的 PASS 替代。
