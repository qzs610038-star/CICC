# 决赛项目文件架构方案 v1.0 定稿

采用“只读资料库 + 干净正式工程 + 独立评审包”的结构。`赛方提供材料/` 和 `初赛demo/` 保持只读；正式开发落到 `final_project/`；方案审核与 Claude/Codex 往返记录放到 `方案评审/001_项目文件架构方案/`。

## 正式工程边界

- `final_project/fpga/rtl/`：正式 FPGA RTL。
- `final_project/fpga/ip_vendor/`：复制入库的赛方/Efinix IP。
- `final_project/fpga/ip_local/`：自建或二次封装 IP。
- `final_project/cpu/app/`：板上 CPU 正式应用。
- `final_project/cpu/params/`：颜色、形状、尺寸、点位和任务配置参数。
- `final_project/integration/`：机器要遵守的接口契约。
- `final_project/docs/`：人要读的设计、调试、操作和证据文档。

## 固定主线

正式路线固定为 FPGA 视频前端/ROI/统计特征/OSD + 板上 CPU 识别决策/参数管理/myCobot 控制。PC、外部 MCU、`pymycobot` 只用于开发期标定和安全验证，不进入最终比赛闭环。

## 关键约定

- 不直接修改 `赛方提供材料/` 和 `初赛demo/`。
- `mem_test.xml` 只引用 `final_project/` 内相对路径。
- HDMI 输出目录采用现有源码习惯命名 `dvi_tx/`。
- 第一版仿真目录固定为 `raw_unpack/`、`roi_crop/`、`feature_extract/`、`cpu_if/`、`osd/`、`dvi_tx/`。
- 总决赛扩展只预留接口：双 UART、双机械臂实例、传送带控制入口。
