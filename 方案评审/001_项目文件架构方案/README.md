# 项目文件架构方案评审包

本目录用于保存决赛项目文件架构方案的审核过程，不承载正式 RTL、CPU 程序或赛方资料副本。

文件状态：

- `项目文件架构方案_v0.2_Codex完善版.md`：根据 Claude 首轮审核补齐后的方案。
- `Claude审核意见.md`：Claude 对方案的审核意见与非阻塞建议。
- `Codex修正说明.md`：Codex 对审核意见的采纳与修正记录。
- `项目文件架构方案_v1.0_定稿版.md`：当前正式落地依据。

正式工程目录为仓库根目录下的 `final_project/`。`赛方提供材料/` 和 `初赛demo/` 默认只读，任何正式开发文件都应复制到 `final_project/` 后再修改。
