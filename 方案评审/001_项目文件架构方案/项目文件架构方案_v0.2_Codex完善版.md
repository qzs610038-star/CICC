# 决赛项目文件架构方案 v0.2

本版根据 Claude 首轮审核修正了 P0/P1/P2 问题：补齐 `dvi_tx/`、`roi_crop/`、RAW/ISP 分层、CPU 工具链、IP 引用策略、`.gitignore`、迁移日志和总决赛扩展槽位。

核心结构：

```text
final_project/
├─ .gitignore
├─ README.md
├─ fpga/
│  ├─ efinity/
│  ├─ rtl/
│  │  ├─ top/
│  │  ├─ common/
│  │  ├─ video_in/
│  │  ├─ raw_unpack/
│  │  ├─ debayer/
│  │  ├─ wb_gamma/
│  │  ├─ roi_crop/
│  │  ├─ feature_extract/
│  │  ├─ framebuffer/
│  │  ├─ osd/
│  │  ├─ dvi_tx/
│  │  ├─ cpu_if/
│  │  ├─ uart_bridge/
│  │  └─ debug/
│  ├─ ip_vendor/
│  ├─ ip_local/
│  ├─ sim/
│  └─ constraints_notes/
├─ cpu/
│  ├─ bsp_vendor/
│  ├─ app/
│  ├─ params/
│  └─ build_tools/
├─ pc_tools/
├─ integration/
├─ tests/
└─ docs/
```

IP 策略采用复制入库并相对路径引用；CPU 工具链迁入最小可构建闭环；总决赛扩展只预留接口，不提前实现复杂逻辑。
